# Siruwa Store

Website toko online yang menyediakan berbagai produk oleh-oleh khas Minangkabau.

## Tujuan
- Memperkenalkan produk lokal Minangkabau.
- Memudahkan pelanggan mendapatkan informasi produk.
- Mendukung pemasaran produk lokal melalui teknologi digital.

## Teknologi
- HTML
- CSS
- JavaScript
- Bootstrap

## Status
Dalam tahap pengembangan.
